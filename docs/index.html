Certified sampling for convex-region libraries

Planners built on graphs of convex sets trust their region library and never re-check what they return. This page shows what that costs — and what a runtime certificate buys back.

Peng Xie · Technical University of Munich · pengxie2024@gmail.com

Every planner in the graphs-of-convex-sets family rests on one sentence: points inside the regions are collision-free. The regions come from a sampling-based generator whose contract is explicitly probabilistic — at confidence 1−δ the colliding volume fraction is at most ε, with ε > 0 by construction. The planning side consumes that contract as a deterministic one. We measured the consequences on a scaled 14-DOF library, and the result is not a rounding error: an optimizer is not a sampler, it is an argmin — an active search for exactly the model surplus that shortens paths.

06Why the fix must be at the answer, not the library

Certainty about a d-dimensional volume must be paid wherever that volume touches obstacles; certainty about the one-dimensional path a robot actually executes is paid only along that path. Three independent routes to volume-level certainty were run to completion, and all three destroy the connectivity planning needs before they deliver soundness where the tasks live:

routecertainty deliveredmeasured cost to the graph
strict Bernoulli gate at generation (ε = 0.1%, enforced) 10× tighter, probabilistic 219 → 47 regions, 2757 → 0 portals
SOS certificates (C-IRIS, 2-DOF testbed) deterministic 7 disconnected islands, 0/30 queries solved
uniform margins (erosion sweep) none (3.4% → 2.6%) queries disconnect first
runtime path certificate deterministic, per answer none — the graph is untouched

The layer composes two ideas on top of the convex decomposition. Safety certificates — one distance query frees a whole ball: clearance φ(q) and the robot's Lipschitz constant L make the ball of radius φ(q)/L provably safe, and overlapping balls chained along a segment are a continuous proof with no resolution parameter and therefore no resolution loophole. Lazy collision checking — most edges are never used by any shortest path, so validate the returned path only, repair in-region or blacklist the edge, re-search. Sparsity (the library is 97% clean) makes validation affordable; the adversarial placement of the residual makes it necessary.

This is not a claim that any published theorem is wrong. Every result in the family is correct relative to its input sets, and the affected papers' own experimental domains largely avoid the regime measured here. What is missing from the literature is the measurement — and a layer that validates the answer a planner actually returns.
